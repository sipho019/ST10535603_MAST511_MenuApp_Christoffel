## App Description
Personal Chef Menu App built with React Native & Expo SDK 57. 
Allows viewing and adding menu items with validation.
Users can add dish name, description, course (starter/main/dessert), and price.

## Features Implemented
- View menu list with FlatList
- Add new menu item with form validation
- Course filtering (Starter / Main / Dessert)
- Price validation
- Clean UI with StyleSheet

## How to Run the App
1. Clone repo: `git clone https://github.com/sipho019/ST10535603_MAST511_MenuApp_Christoffel.git`
2. Install dependencies: `npm install`
3. Start Expo: `npx expo start`
4. Scan QR with Expo Go app
